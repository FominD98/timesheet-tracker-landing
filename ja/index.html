金曜日、17:42。

工数は、まだ1行も入っていません。

火曜日のことは、もう思い出せない。チケット、レビュー、打ち合わせ、「ちょっといいですか」。5日分の作業を、記憶とチャットの履歴とブラウザーのタブから組み立て直すことになります。
Jiraはタスクごとに作業ログを求めます。課題を開き、作業を記録し、説明を書き、日付を選ぶ。これをタスクの数だけ、1週間の毎日くり返します。
タイマーは実際の仕事についてこられない。押し忘れ、止め忘れ。しかも昼までに20回はタスクを切り替えています。

使い方

記録して、仕分けて、確定する。

タイマーの操作も、チケット番号の暗記も不要です。3つのステップのうち、あなたの出番は最後の1つだけです。

タスクごとに作業ログは1つ

各タスクに1日1行のわかりやすい説明を。「開発作業」のような決まり文句ではなく、実際にやった作業から書きます。

本当に迷う箇所だけを確認

アプリが判断できないブロックには、可能性の高い候補が2～3個表示されます。それ以外はすべて入力済みです。

2回送っても安全

登録済みの日は自動で認識されるので、再送してもJiraの工数が二重に計上されることはありません。

機能

Jiraに強い、自動の工数管理ツール

Jiraで工数を入力する開発者、アナリスト、コンサルタント、制作会社の方へ。工数入力のことは、もう考えなくて大丈夫です。

JiraキーはPC上で検出、AI不要

課題キーはウィンドウタイトル、ブラウザーのタブ、プルリクエスト、gitブランチ名から即座に拾われます。処理はすべてあなたのPC上で行われます。

feature/CASE-1423-token/browse/OPS-77[CASE-1388] レビュー

AIで「この日を仕分け」

ルールで割り当てられなかったブロック（Figmaのファイル、Slackのスレッド、Confluenceのページなど）を、ワンクリックで確信度つきで割り当てます。

作業ログの文面も下書き

実際に触ったものをもとに、タスクごとに短く具体的な説明を1つ作ります。例：「billingのPR #412・#418をレビュー」。

主導権はあなたに

確定するまで何も記録されません。確認画面でタスクを変更したり、ブロックを分割したり、「業務外」にしたりできます。

Jira Cloud と Data Center

作業ログはあなた自身のアカウントで Jira Cloud または Jira Server / Data Center に書き込まれます。再送しても重複しません。

離席と画面ロックを検出

昼休み、画面ロック、席を外した時間は「離席」として扱われ、工数に紛れ込むことはありません。

CSVエクスポート Excel・Tempo対応予定

Excelの工数管理表や別のシステムで使いたいときは、確定した1週間分をCSVで書き出せます。XLSXとTempoへの直接対応も予定しています。

「AIなしで使用」モード

PCの外に何も出したくないなら、AIをオフに。キーとルールによる照合はPC上で続き、残りは手動で割り当てます。

通知領域に常駐

PCと一緒に起動し、作業の邪魔をしないネイティブのWindowsアプリです。開いておくブラウザーのタブも、覚えておくタイマーもありません。

設計段階からプライバシーを保護

スクリーンショットなし。監視もなし。

アクティビティの記録はあなたのものです。データはPCに残り、AIが見るのはマスク済みの要約だけ。それも、ボタンを押したときだけです。

PCに残るもの

PC上で記録され、アップロードされません。

  • アクティブなプログラムとウィンドウタイトル
  • ブラウザーのタブのドメイン
  • 離席と画面ロックの時間
  • ルール、履歴、確認画面での修正
  • Jiraの接続設定

「この日を仕分け」のときだけ送信

ルールで照合できなかったブロックについてのみ。

  • ウィンドウタイトル（メールアドレスや数字はマスク）
  • プログラム名
  • ドメイン（完全なアドレスではありません）
  • 各ブロックの長さ

送信も取得もしないもの

そもそも収集しないので、漏れることもありません。

  • 完全なURLとページの内容
  • スクリーンショットや画面録画
  • キー入力
  • Jiraのトークン

工数を入力する本人のためのツールです。上司向けダッシュボードなし従業員の監視なしチームレポートなし

よくある質問

よくある質問

Timesheet Trackerは従業員監視ツールですか？

いいえ。工数を入力する本人のためのツールです。スクリーンショット、キー入力の記録、上司向けダッシュボード、チームレポートはありません。アクティビティはあなたのPCに残り、Jiraに送られるのはあなたが確定した作業ログだけです。

勤怠管理システムの代わりになりますか？

いいえ。Jiraへの工数入力（作業ログ）のための個人用ツールで、会社の勤怠管理システムや、出退勤・労働時間の記録を置き換えるものではありません。

PCの外に出るデータは何ですか？

あなたが操作するまでは何も出ません。「この日を仕分け」を押すと、未割り当てブロックのマスク済みウィンドウタイトル、プログラム名、ドメイン、時間がAIに送られます。完全なURL、ページの内容、スクリーンショット、キー入力、Jiraのトークンは送信されません。1日を確定すると、承認した作業ログがあなたのJiraに送られます。詳しくはプライバシーポリシー（英語）をご覧ください。

AIなしでも使えますか？

はい。「AIなしで使用」モードでは、AIプロバイダーには何も送られません。ウィンドウタイトル、URL、gitブランチにあるJiraキーは引き続きPC上で照合され、残りのブロックは確認画面で自分で割り当てます。

対応しているJiraは？

Jira Cloud と Jira Server / Data Center です。作業ログはあなた自身のアカウントで書き込まれ、同じ日を再送しても重複しません。Jiraでの工数管理の基本は工数管理を自動化する方法（Jira）で解説しています。

どのJiraタスクで作業したか、どうやって判断するのですか？

1日の大部分はAIを使わずに照合されます。ABC-123のようなJiraキーは、ウィンドウタイトル、ブラウザーのタブ、プルリクエスト名、feature/ABC-123-loginのようなgitブランチ名に現れるからです。AIが扱うのは残りの部分だけで、記録される前にすべての割り当てをあなたが確定します。

TempoやExcelには対応していますか？

現在は、Jiraネイティブの作業ログの書き込みとCSVエクスポートに対応しています。Tempoへの直接対応とExcel（XLSX）への書き出しは予定しています。

料金はいくらですか？

Microsoft Storeから無料でダウンロードでき、まずProを14日間無料で試用できます（カード不要）。その後Proは月額$9.99、または年額$79（月あたり約$6.58、34%お得）で、既定は年額プランです。サブスクリプションがなくても記録は続き、1日の画面、7日分の履歴、当日のCSVエクスポートを利用できます。Jiraへの作業ログの送信とAIによる仕分けにはProが必要です。

どこからダウンロードできますか？

Microsoft Storeから。「工数管理・タイムトラッカー - Jira用AI」という名前で公開しています（英語名：Time Tracker & Timesheet - AI for Jira）。ダウンロードは無料で、Proを14日間無料で試用できます（カード不要）。

Mac版やLinux版はありますか？

まだありません。Timesheet TrackerはWindowsアプリです。ほかのプラットフォームが必要な場合は、help@timesheet-tracker.com までお知らせください。
